RAPP Agent Converter

The agent travels inside the skill.

Project a RAPP single-file agent into an Agent Skill without translating it. The generated SKILL.md embeds the complete Python and ships a byte-exact linked agent beside it. Restoring is checksum-verified, never a re-render.
